## Switch-on checklist (in order, ~20 minutes once keys exist)

Timings assume the backend, MCP and frontend streams are merged and `npm run dev` is green.

1. **(2 min) Supabase project.** supabase.com/dashboard → New project `steward`. While it provisions, open `supabase/migrations/0001_reality.sql`.
2. **(2 min) Supabase schema.** SQL Editor → paste the migration → Run → paste `supabase/seed.sql` → Run. Verify: `select tablename from pg_publication_tables where pubname='supabase_realtime';` returns `changes, facts, work_items`.
3. **(1 min) Supabase keys.** Settings → API Keys. `backend/.env`: `SUPABASE_URL=https://<ref>.supabase.co`, `SUPABASE_SERVICE_KEY=sb_secret_…`. `frontend/.env.local`: `NEXT_PUBLIC_SUPABASE_URL=` same URL, `NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_…`.
4. **(3 min) Inkbox identity.** Console → admin API key → `backend/.env`: `INKBOX_API_KEY=…`. Run the `create_identity("steward-harbor", phone_number={"type":"local"})` snippet from docs/INKBOX.md §2 (Developer plan for the phone). Record handle, email, phone. `INKBOX_IDENTITY=steward-harbor`.
5. **(1 min) Inkbox recipients + gates.** `backend/.env`: `INKBOX_CONTRACTOR_PHONE`, `INKBOX_OWNER_PHONE`, `INKBOX_CONTRACTOR_EMAIL`, `INKBOX_ALLOWED_RECIPIENTS=<all three>`, `STEWARD_ALLOW_EXTERNAL_MESSAGES=true`, `STEWARD_INBOUND_SECRET=$(python3 -c 'import secrets;print(secrets.token_urlsafe(32))')`. Teammate texts **START** to the Steward number now (SMS opt-in; number needs ~10–15 min after provisioning before `sms_status` is `ready`).
6. **(1 min) Tunnel.** New terminal: the `inkbox.tunnels.connect(name="steward-harbor", forward_to="http://127.0.0.1:8001")` snippet from docs/INKBOX.md §4. Copy the printed `https://steward-harbor.inkboxwire.com` → `backend/.env`: `STEWARD_PUBLIC_BASE_URL=`. Leave the terminal running.
7. **(1 min) Inkbox webhook.** Run the `webhooks.subscriptions.create(...)` snippet from docs/INKBOX.md §5 with `url=<tunnel>/api/inbound/inkbox`, `auth_token=<STEWARD_INBOUND_SECRET>`. Paste the one-time `signing_key` → `backend/.env`: `INKBOX_WEBHOOK_SIGNING_KEY=`. Optional: whitelist contact rules (§8).
8. **(1 min) Restart backend.** Ctrl+C `npm run dev`, run it again. Check `curl -s http://127.0.0.1:8001/api/integrations` shows inkbox configured and, after the first upsert, supabase `connected`. Check `curl -s https://steward-harbor.inkboxwire.com/api/integrations` answers through the tunnel.
9. **(2 min) Armature key.** app.armature.tech → MCP Setup → Add MCP server (name `steward`, URL to be filled after step 11) → Connect SDK analytics → copy key (+ URL if EU). Keep for step 10. Settings → API keys → mint a dashboard key for evals; keep it only on the laptop.
10. **(3 min) Manufact deploy.** `npx -y mcp-use@latest login`, then `STEWARD_BACKEND_URL=https://steward-harbor.inkboxwire.com ARMATURE_API_KEY=<ingest key> bash manufact/deploy.sh`. Wait for "Health Checks → Complete". Copy the printed `https://<slug>.run.mcp-use.com/mcp`. In the Manufact server: Settings → Analytics capture → enable **Capture payloads** and **Identify actors**.
11. **(1 min) Connect Claude Code.** Manufact server page → URL chip → Add to client → Claude Code (or `claude mcp add --transport http steward https://<slug>.run.mcp-use.com/mcp`). In Claude Code: `list_sites`, then `resolve harbor P-101 commissioning_certificate`. Confirm the session appears in Manufact → Sessions.
12. **(1 min) Armature evals.** Back in Armature MCP Setup, set the server URL to the Manufact URL. Evaluation → Create eval suite "Steward demo workflow" → create the five cases from `armature/evals/steward-demo-suite.json` → Run suite. (Or the `curl …/workflows/<EVAL_CASE_ID>/runs` loop in armature/README.md §4.) Confirm a session shows under Armature → Sessions if the SDK hook took; if not, the eval runs are the judge-visible evidence.
13. **(1 min) Publish checks.** Manufact → Publish → Checklist → Run ($0.10). Screenshot the score. Optional on Hobby: Publish → Public Chat → on, add three suggested questions.
14. **(1 min) Dry run.** Claude Code: "Clear Harbor Works for restart. Sign off nothing you cannot prove. Budget $5." Phone receives the card; wrong photo → rejected on the thread; right photo → accepted; `check` returns `valid: true`; Supabase `attestations` has the row; Manufact Sessions and Armature show the calls.

If anything in 4–7 fails, skip to 10 with the MCP pointed at a local tunnel-less backend omitted (`STEWARD_BACKEND_URL` must be reachable; without the tunnel do not deploy) and run the demo in local mode; the backup recording covers 0:40–1:30.
